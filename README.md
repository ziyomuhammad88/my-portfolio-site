# Бот для оформления постов о сделках

Ты присылаешь боту фото сделки с подписью-комментарием → Gemini переписывает
комментарий в аккуратный пост → бот показывает черновик с кнопками
«Опубликовать» / «Отмена» → только после твоего подтверждения пост уходит в
канал. Если что-то не устраивает — пишешь боту, что поправить, он
перегенерирует черновик и снова спрашивает подтверждение.

## 1. Создать бота

1. В Telegram открой [@BotFather](https://t.me/BotFather), отправь `/newbot`
   и следуй инструкциям. В конце получишь токен вида `123456:ABC-DEF...` —
   это `TELEGRAM_BOT_TOKEN`.

## 2. Получить ключ Gemini API

1. Зайди на [Google AI Studio](https://aistudio.google.com/apikey), создай
   ключ — это `GEMINI_API_KEY`. У Gemini API есть бесплатный лимит запросов,
   для большего объёма подключается платный тариф в Google Cloud (см.
   [ai.google.dev/pricing](https://ai.google.dev/gemini-api/docs/pricing)).

## 3. Узнать свой user_id

1. Напиши в Telegram боту [@userinfobot](https://t.me/userinfobot) — он
   пришлёт твой числовой ID. Это `ADMIN_USER_ID`. Бот будет реагировать
   только на сообщения от этого ID — так никто посторонний не сможет ничего
   опубликовать через него.

## 4. Добавить бота в канал

1. Открой свой канал → Управление каналом → Администраторы → Добавить
   администратора → найди своего бота по username → выдай ему право
   **публиковать сообщения**.
2. Узнать `CHANNEL_ID`:
   - если канал публичный — просто используй `@username_канала`;
   - если приватный — перешли любое сообщение из канала боту
     [@userinfobot](https://t.me/userinfobot) или
     [@JsonDumpBot](https://t.me/JsonDumpBot), он покажет `chat.id` вида
     `-1001234567890`.

## 5. Установить и запустить

```bash
cd trading-bot
python3 -m venv venv
source venv/bin/activate      # на Windows: venv\Scripts\activate
pip install -r requirements.txt

cp .env.example .env
# открой .env и заполни все значения
```

Запуск:

```bash
python3 bot.py
```

В консоли появится `Бот запущен, жду сообщения…`. Теперь напиши боту в
личку, пришли фото сделки с подписью — и проверь весь цикл до публикации в
тестовом/приватном канале, прежде чем использовать на боевом.

## Как это работает дальше без твоего участия за компьютером

Пока скрипт запущен (`python3 bot.py`), бот работает. Если закроешь терминал
или выключишь компьютер — бот перестанет отвечать. Варианты, чтобы он работал
постоянно:

- оставлять запущенным на компьютере через `screen`/`tmux`, чтобы не
  обрывалось при закрытии терминала;
- перенести на недорогой VPS (Timeweb, Beget и т.п.) и запускать там как
  systemd-сервис;
- задеплоить на сервис вроде Railway/Render (есть бесплатные лимиты для
  небольших ботов).

Для первого знакомства достаточно просто запускать на своём компьютере,
когда собираешься постить сделки.

## Как настроить стиль постов

Стиль и структура поста заданы в `SYSTEM_PROMPT` внутри `bot.py`. Если
захочешь другую структуру, тон или набор эмодзи — просто отредактируй этот
текст, ничего больше менять не нужно.

## Если что-то пошло не так

- **`KeyError` при запуске** — не заполнено одно из полей в `.env`.
- **Бот не публикует в канал** — проверь, что бот добавлен админом канала с
  правом публикации сообщений, и что `CHANNEL_ID` указан верно.
- **Ошибка от Gemini API** — проверь `GEMINI_API_KEY` в
  [Google AI Studio](https://aistudio.google.com/apikey).
- **Модель не найдена (model not found)** — актуальные имена моделей могли
  измениться, проверь список на ai.google.dev/gemini-api/docs/models и
  поправь `GEMINI_MODEL` в `.env`.
